# AIGC Video Generation | Research & Workflow

AI视频生成技术研究 · 模型能力分析 · 工作流实践

## 关于本项目

本仓库用于记录个人在AIGC视频生成领域的技术探索、
模型测试、工作流实践及问题分析。

重点关注不同生成模型的能力边界、视觉控制策略、
角色一致性、动作迁移及多模型协同。

研究方式以实际项目为基础，通过问题分析、
方案测试、结果对比及经验总结，
探索更稳定、高效、可控的AI视频生成方法。

## 研究方向

### 01. Video Motion Transfer
参考视频动作迁移与人物替换

研究复杂动作复刻、人物替换、
道具交互及原始场景保留等问题。

### 02. Character Consistency
AI角色一致性控制

研究角色资产制作、多角度视觉一致性、
人物特征保持与跨镜头稳定性。

### 03. Model Capability Analysis
视频生成模型能力分析

研究不同模型在动作、运镜、光影、
画面连续性及复杂场景生成中的表现。

### 04. Workflow Research
AI视频工作流研究

探索多模型协同、生成策略优化、
工作流设计及制作效率提升。

## 技术研究方法

Problem → Analysis → Experiment → Result → Optimization

问题发现 → 原因分析 → 方案测试 → 结果记录 → 迭代优化
